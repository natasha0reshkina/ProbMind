# ProbMind

## Как зайти как студент и весь функционал

Приложение доступно по адресу http://127.0.0.1:8080.

Логин: student@probmind.local  
Пароль: Student123!

Демонстрационный аккаунт: student01@demo.probmind.local  
Пароль: DemoStudent123!

Студенту доступны личный кабинет, диагностики, практика, экзамены, интервальное повторение, план повторения, уверенность в ответах, материалы и задачи, индивидуальные задания, рейтинг, стрики, достижения, уведомления и учебные циклы до и после материала.

Диагностика может быть адаптивной или назначенной преподавателем. Поддерживаются персональные, групповые и общие назначения. Во время ответа студент может указать степень уверенности, ход рассуждения и комментарий преподавателю. После завершения доступны результаты по темам, история, типичные ошибки и рекомендации.

Практика формируется по теме, текущему уровню и выявленным ошибкам. Поддерживаются коррекционные задания, задания на перенос знания и интервальное повторение. Все результаты, достижения, стрики и учебный прогресс рассчитываются отдельно для каждого студента.

## Как зайти как преподаватель и весь функционал

Приложение доступно по адресу http://127.0.0.1:8080.

Логин: teacher@probmind.local  
Пароль: Teacher123!

Преподавателю доступны список студентов, профили студентов, группы, конструктор диагностик, банк заданий, импорт CSV, экзамены, индивидуальные задания, материалы, учебные циклы, рейтинг, стрики, статистика заданий, уверенность студентов, экспорт и аналитика.

Диагностики и экзамены можно назначать всем студентам, группе или конкретному студенту. Преподаватель может изменять аудиторию, публиковать и скрывать диагностики, создавать задания, добавлять версии, фильтровать банк по теме и сложности.

После завершения экзамена всей назначенной аудиторией доступен просмотр ответов каждого студента, правильных ответов, результата, степени уверенности, времени ответа, хода рассуждения и комментариев.

## Как зайти как администратор и весь функционал

Приложение доступно по адресу http://127.0.0.1:8080.

Логин: admin@probmind.local  
Пароль: Admin123!

Администратору доступны управление пользователями, смена ролей, активация аккаунтов, журнал аудита, состояние API и инфраструктуры, метрики запросов и ошибок, а также весь преподавательский функционал и расширенная статистика.

Служебные интеграционные аккаунты скрыты из обычных списков пользователей.

## Полное описание архитектуры

ProbMind состоит из React frontend, ASP.NET Core API, .NET Worker, PostgreSQL и Redis. Локальная среда запускается через Docker Compose.

### Frontend

Frontend реализован на React, TypeScript и Vite. Маршрутизация и интерфейс разделены по ролям. TanStack Query используется для серверного состояния, Axios для API запросов. Пользовательский кэш очищается при смене аккаунта.

### Backend

Backend разделён на Domain, Application, Infrastructure, Api и Worker.

Domain содержит предметную логику и модели.

Application содержит сценарии, сервисы, контракты и валидацию.

Infrastructure отвечает за PostgreSQL, Redis, репозитории, безопасность и начальные данные.

Api предоставляет HTTP endpoints и ролевую авторизацию.

Worker выполняет фоновые пересчёты.

### PostgreSQL

PostgreSQL хранит пользователей, задания, диагностики, практику, освоение тем, типичные ошибки, группы, назначения, экзамены, достижения, материалы, рекомендации и аудит.

Персональные данные привязаны к UserId или StudentId.

### Redis

Redis используется для кэша, очереди фоновых задач и идемпотентности запросов.

### Авторизация

Авторизация основана на JWT и refresh token.

Роли Student, Teacher и Admin проверяются на backend.

Пароли хранятся в виде PBKDF2 хеша.

### Обучающая логика

Адаптивная диагностика учитывает тему, освоение, ошибки, сложность и историю заданий.

Практика строится на индивидуальной модели студента.

Диагностики, экзамены и индивидуальные задания поддерживают общую, групповую и персональную аудиторию.

### Тестирование

Тесты разделены на unit и integration.

CI собирает backend, запускает тесты и собирает frontend.
